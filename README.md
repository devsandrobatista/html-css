## 📌 Sobre este Repositório

Este repositório reúne todo o conteúdo estudado no curso de HTML5 e CSS3 do Curso em Vídeo, organizado conforme a estrutura didática do curso.

Aqui estão armazenados exercícios, desafios, exemplos e projetos práticos, exatamente como apresentados ao longo das aulas, com o objetivo de acompanhar a evolução do aprendizado e facilitar revisões futuras.

## 🧭 Como navegar pelo repositório

O conteúdo está organizado por módulos e aulas, seguindo a progressão do curso:

- 📂 Pastas por módulo

- 🧩 Exercícios práticos

- 🚀 Desafios propostos em aula

- 🌐 Projetos desenvolvidos durante o curso

Cada pasta representa uma etapa do aprendizado.

## 🎯 Objetivo

- Centralizar todo o material do curso em um único repositório

- Acompanhar a evolução nos estudos de HTML e CSS

- Servir como material de consulta e revisão

- Manter os exemplos conforme a didática original do curso

## 🛠️ Tecnologias Estudadas

- HTML5

- CSS3

- Layout Responsivo

- Media Queries

- Boas práticas de estruturação

## 📚 Sobre o Curso

O conteúdo deste repositório é baseado no curso HTML5 e CSS3 do Curso em Vídeo, ministrado pelo professor Gustavo Guanabara.

Este repositório tem finalidade exclusivamente educacional.

## 🚀 Como utilizar

Navegue pelos arquivos diretamente no GitHub

Clone o repositório para estudo local:

    git clone https://github.com/devsandrobatista/html-css.git

Abra os arquivos **.html** no navegador ou utilize **Live Server**
